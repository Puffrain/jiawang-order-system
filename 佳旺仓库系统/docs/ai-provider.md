# DeepSeek 接入

真实视觉能力不能由 API Key 推断。管理员必须设置 Base URL、API 路径、视觉模型、输入模式和价格表，然后用固定小图片执行 `probe()`。探测失败时显示清晰错误，任务转入 `manual_required`，人工流程仍可继续。

适配器只接收应用生成的压缩图片字节，不把本地路径或未经允许的 URL 传给供应商。请求和响应保存 request id、模型、提示版本、usage 状态和响应哈希；原始 Authorization、图片内容和完整敏感响应不得写日志。

模型输出必须经过 schema 校验。无法解析、字段冲突、类别不存在或 usage 不明都标记为待人工处理。价格表按版本快照到任务，token 预算在请求前原子预留，未知计费结果不会按零计算。
