# DECISIONS

## D-001 绿地架构

目标目录为空，按新项目实现，不复制相邻订单系统的业务耦合代码。

## D-002 存储

SQLite 使用 WAL；数据库和媒体放 Docker/WSL2 Linux 命名卷。OneDrive 仅保存源码和人工下载的备份，不承载 live 数据库。

## D-003 AI

使用可插拔 DeepSeek 视觉适配器。API Key 目前可用，但视觉 Base URL、模型 ID、输入模式和 usage 能力必须显式配置并探测；没有硬编码视觉模型名。

## D-004 审核与导出

强制人工审核；只有 published 数据可默认导出。审核员可批准发布，所有决策写入审计。

## D-005 备份

不做自动定时备份。管理员手动生成加密完整包，恢复前自动留底并支持原子回滚。
