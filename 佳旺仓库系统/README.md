# 佳旺美容美发商品录入系统

用于把美容美发商品的多角度图片 ZIP 转换为可人工审核的商品库。系统保留不可变原图，使用压缩派生图进行视角分类、同商品分组和背标字段提取，并支持 Excel/CSV 导出、token/费用监测、权限控制和加密备份恢复。

## 当前状态

这是从零建立的项目。真实 DeepSeek 视觉端点和模型名必须在部署配置中显式提供；在此之前可使用 mock provider 完成离线开发和测试。任何未探测通过的视觉端点都不会接收商品图片。

## 本地开发

1. 复制 `.env.example` 为 `.env`，设置随机的会话、主密钥和初始管理员凭据。
2. 使用 Node 20 LTS 和 pnpm 安装依赖：`corepack enable`、`pnpm install`。
3. 运行 `pnpm dev`，默认打开 `http://localhost:3000`。
4. 运行 `pnpm lint`、`pnpm typecheck` 和 `pnpm test`。

生产运行使用 `docker compose up --build`。SQLite 数据库和媒体必须使用 Docker 命名卷，不要将 `/data` 绑定到 OneDrive、SMB 或网络盘。HTTPS 证书由反向代理配置提供。

## 首次配置

管理员登录后在“系统设置 → AI 接入”中填写 DeepSeek Base URL、视觉模型、输入模式和价格表并执行能力探测。API Key 可由环境变量注入，也可在设置页使用 `APP_MASTER_KEY` 加密保存；环境变量优先，界面只显示脱敏指纹。

## 数据规则

- 只接受 JPG、PNG、WebP；原图长期保留，派生图去除 EXIF/GPS。
- 条码按文本保存，支持 EAN-13、UPC-A、Code128；冲突必须人工处理。
- AI 只生成建议和证据。商品名、分类、至少一个规格/包装单位经人工确认后才可发布。
- 默认导出只包含已发布数据；只读账号不能修改、审核、备份或读取原始文件。

## 部署与灾备

管理员手动生成加密 `.jwbackup`，下载到受控的主机目录。恢复会先生成当前实例留底、校验 manifest 和 SQLite 完整性，再原子切换并撤销现有会话。备份密码丢失时无法恢复，系统不会绕过加密。

详见 `docs/` 下的部署、安全、AI 接入、审核流程和备份恢复说明。
