# 全流程回归清单

## 老板端
- [ ] 未登录访问后台立即进入老板登录页，不闪现后台内容。
- [ ] 错误密码显示统一错误，不泄露账号是否存在。
- [ ] 连续错误触发限流。
- [ ] 登录后刷新会话仍有效；退出后受保护页面不可访问。
- [ ] 查看订单、改价、沿用历史价、发送消息均落库。
- [ ] 三种 A4 单据字段正确，拣货单无价格。
- [ ] 订单、客户、商品导出内容真实并生成审计日志。
- [ ] 新增商品支持多规格、独立库存和不重叠的阶梯价。
- [ ] 商品可上下架和归档，归档后不能继续编辑、定价或购买。
- [ ] 抽屉关闭时未保存内容会二次确认，保存后列表立即刷新。
- [ ] 图片限制为每商品 8 张、每张 5MB，支持排序、主图和删除。
- [ ] 图片扩展名、声明 MIME 与文件真实签名不一致时上传失败。
- [ ] 上传文件使用系统生成文件名，未登录及买家上传均被拒绝。
- [ ] 下架商品和图片对买家不可见，上架后主图与全部规格同步出现。
- [ ] 运行 `pnpm run test:product-flow`，验证商品、上传、定价与归档全流程。

## 买家端
- [ ] 未登录访问商城进入买家登录页。
- [ ] 验证码发送有倒计时、过期、单次使用和频率限制。
- [ ] 新手机号通过验证码后自动创建客户账号并进入商城，不强制设置密码。
- [ ] 已注册客户可继续使用短信验证码登录；已设置密码的客户也可使用次要密码入口。
- [ ] 登录验证码不能用于密码重置，重置验证码不能用于短信登录。
- [ ] 无密码客户可在“我的”直接设置密码；已有密码客户修改时必须通过短信验证，成功后其他会话失效。
- [ ] 短信服务未配置时，页面明确提示联系商户；已有密码客户仍可登录。
- [ ] 运行 `pnpm run test:customer-auth`，验证自动开户、双登录、密码设置与用途隔离。
- [ ] 商品搜索、阶梯价、加购、购物车刷新后保留。
- [ ] 提交订单由服务端重算价格并扣减库存。
- [ ] 客户提交成功后，老板订单接口立即能按订单号、手机号和金额查询。
- [ ] 老板后台保持打开时，新订单会在 15 秒内自动出现，手动刷新可立即同步。
- [ ] 订单接口失败时保留旧列表并显示错误和重试入口，不显示“暂无订单”。
- [ ] 运行 `pnpm run test:order-visibility`，验证订单统一落库和角色可见性。
- [ ] 买家只能查看自己的订单、地址和消息。
- [ ] 退出后无法访问商城和个人数据。

## 安全
- [ ] 伪造 Cookie、过期会话、跨源写请求失败。
- [ ] 客户 ID、操作人 ID、价格、总额由客户端篡改时无效。
- [ ] 导出文本以 `= + - @` 开头时不会触发表格公式。
- [ ] 错误响应不包含 SQL、堆栈、密码、令牌或验证码摘要。
- [ ] 所有核心按钮可点击、无覆盖、无控制台异常。

## 路由与分块稳定性
- [ ] 全新浏览器上下文直接访问 `/`、`/buyer`、`/customer-entry`、`/diagnostics/buttons`，重定向链与最终页面状态正确。
- [ ] 首次加载、强制刷新、前进后退和新窗口打开均不出现 `Router action dispatched before initialization`。
- [ ] 页面 HTML 引用的全部 `/_next/static/**` 资源返回 200，且不返回登录页 HTML或鉴权重定向。
- [ ] 连续修改客户端组件触发至少 10 次热更新后，后台登录页与买家登录页仍可交互。
- [ ] 诊断页 iframe 切换目标、重载和新窗口打开后无 `ChunkLoadError`、RSC 网络失败或无响应按钮。
- [ ] 错误上报组件在 Fast Refresh/full reload 后只保留一组监听器，不重复包装 `fetch`。
- [ ] 开发预览使用固定的 webpack 模式；生产构建仍使用标准 `next build`。
- [ ] 运行 `pnpm run test:router-chunks`，保存入口重定向链和静态资源检查结果。
- [ ] 运行 `pnpm run test:security`，确认认证基线没有被开发模式调整破坏。
- [ ] 运行 ESLint、TypeScript 与生产构建，确认修复不只对开发预览有效。
