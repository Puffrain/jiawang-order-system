## 本地配置边界

以下文件属于开发者工具本地状态，不能覆盖、合并或提交到发布分支：

- miniprogram/project.config.json
- miniprogram/project.private.config.json
- .env*、证书、私钥、数据库、上传资源和运行日志

真实微信登录、支付和真机视觉验收必须在微信开发者工具及受控服务器环境完成，静态检查不能替代这些验收。

## 构建约定

当前路径层级在 Windows 下会使默认 Turbopack 构建写入 source map 时超过文件系统路径限制。发布前使用 pnpm exec next build --webpack。

后续若迁移到短路径检出目录，可重新评估是否恢复默认 Turbopack。
