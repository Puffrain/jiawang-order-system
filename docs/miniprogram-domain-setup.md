# 小程序合法域名配置

开发者工具中出现“请求合法域名校验出错”时，需要在微信公众平台添加服务器域名。

1. 登录微信公众平台，进入对应小程序。
2. 打开“开发”->“开发管理”->“开发设置”。
3. 找到“服务器域名”，在“request合法域名”中添加：

   `https://www.kunshanjiawang.cn`

4. 保存后回到微信开发者工具，点击“编译”或重启项目。

说明：

- 只填写域名，不填写接口路径，例如不要填写 `/api/auth/wechat/login`。
- 必须使用 HTTPS，证书域名要和填写的域名一致。
- 真机调试也会执行这项校验；不要把“详情->本地设置->不校验合法域名”当作生产配置。
- 当前小程序接口基地址在 `miniprogram/app.js` 中设置为该 HTTPS 域名。
