# 功能与安全基线矩阵

## 页面入口

| 区域 | 路径 | 当前风险 | 目标保护 |
|---|---|---|---|
| 商户后台 | `/` | 硬编码数据；无登录拦截 | 仅 `owner` 会话 |
| 老板登录 | `/admin/login` | 缺失 | 手机号 + 密码 + 限流 |
| 买家商城 | `/buyer` | 无真实会话；客户端演示状态 | 仅 `buyer` 会话 |
| 买家登录 | `/buyer/login` | 固定演示验证码 | 服务端验证码挑战 |
| 客户二维码 | `/customer-entry` | 公开是合理的 | 保持公开，仅生成登录入口 |
| 按钮诊断 | `/diagnostics/buttons` | 可读取后台页面 | 仅老板 |
| 上线资料 | `/setup-guide` | 含内部上线信息 | 仅老板 |

## API 基线

| API | 现状 | 风险/阻断 | 目标 |
|---|---|---|---|
| `/api/messages` | 接受客户端用户 ID | 可冒充发件人 | 从会话读取身份 |
| `/api/orders/price` | 接受 operator/customer | 越权改价 | 仅老板，服务端操作者 |
| `/api/customers/export` | 硬编码 CSV | 无权限、无审计 | 真实数据、仅老板 |
| `/api/qr` | 公开代理 | 可被滥用 | 限长度、仅允许本站登录 URL |
| `/api/docs/setup` | 公开下载 | 泄露内部资料 | 仅老板 |
| `/api/health` | 公开 | 当前可接受 | 只返回最小状态 |

## 可点击元素基线

- 买家登录：获取验证码、登录按钮当前为演示逻辑。
- 买家商城：加购只更新客户端数字，刷新丢失；无真实购物车与提交订单。
- 商户后台：商品管理与系统设置为占位；改价仅局部展示，确认未完整落库。
- 客户导出按钮与现有导出 API 未绑定真实筛选数据。
- 打印入口缺失。
- 复制操作在预览权限策略下可能被浏览器阻止，必须提供可选中文本和下载替代。

## 数据流基线

- 页面主要数据来自前端常量。
- SQLite 仅保存聊天消息、改价日志、客户扩展表和历史价表。
- 订单、商品、购物车、账号、会话、验证码、地址、审计表缺失。
- 客户 ID、操作人 ID 和价格可由客户端传入，服务端信任边界错误。

## 外部服务阻断项

- 正式短信供应商、签名和模板未提供。
- 支付宝/微信支付商户资料未提供。
- 快递查询与电子面单账号未提供。
- 正式域名、店铺抬头、打印电话/地址仍需确认。

## 已观察运行时问题

- 热更新期间出现过 `Router action dispatched before initialization`。
- 依赖变化后出现过旧 chunk 加载失败；刷新后可恢复，需在最终构建回归中确认无复现。
- 预览环境 Clipboard 权限可能被禁用，不能把复制成功作为唯一操作路径。

## 自动化基线

`tests/security/auth-baseline.mjs` 检查：

1. 未登录访问后台是否跳转老板登录。
2. 未登录访问买家商城是否跳转买家登录。
3. 未登录调用老板 API 是否返回 401。
4. 买家不能调用老板导出/打印接口。
5. 健康检查公开且不泄露内部信息。
