# 上线前需提供资料清单

## 必须配置

- `SESSION_SECRET`：至少 32 位随机字符串，用于签发登录身份标记；更换后现有会话全部失效。
- `OWNER_PHONE`：唯一老板登录手机号，当前项目默认为 `13806265100`。
- `OWNER_PASSWORD`：至少 10 位强密码，仅通过平台密钥配置注入，禁止写入代码或文档。
- 正式站点使用 HTTPS；客户二维码应在正式域名的 `/admin/customer-qr` 页面重新下载，二维码目标固定为正式域名的 `/customer-entry`。

## 正式入口

- 客户地址：`https://luffy-b64dcf22.run4.luxiaofei.cc/`
- 客户二维码入口：`https://luffy-b64dcf22.run4.luxiaofei.cc/customer-entry`
- 商户地址：`https://luffy-b64dcf22.run4.luxiaofei.cc/admin`
- 商户登录页：`https://luffy-b64dcf22.run4.luxiaofei.cc/admin/login`
- `e2b.app` 地址只用于开发预览，不应交付给客户或商户。
- 商户首次登录后应在后台“账号安全”中修改初始密码。

## 短信服务

- 当前开发环境会在验证码页面明确显示“开发环境测试码”。
- 生产环境必须提供短信供应商账号、签名、模板和 `SMS_PROVIDER_TOKEN`，并完成供应商适配后才可发送。
- 未配置时系统会阻断验证码登录并提示，不会显示固定验证码或伪造发送成功。

## 支付与物流

- 当前订单提交后进入“待商户审核”，不会自动扣款。
- 未接入支付渠道前，不得将订单状态或页面文案改成“支付成功”。
- 正式收款需另行提供支付渠道商户资料；物流回传需提供承运商接口资料。

## 数据与运维

- SQLite 文件位于 `data/`，生产环境由命名数据卷持久化。
- 应制定数据库备份、恢复演练、数据保留和账号离职交接制度。
- 定期查看审计日志、失败登录、验证码频率和导出记录。
- 老板导出的 CSV 含客户资料，应妥善保存并限制传播。

## 上线验收

- 老板与买家分别完成登录、退出、越权访问和限流测试。
- 买家完成商品选购、阶梯价、库存校验、地址、下单和订单查询。
- 老板完成改价、状态流转、三种 A4 打印和三类 CSV 导出。
- 验证 `/api/health` 只返回 `{ "ok": true }`，内部资料接口仅老板可访问。

## 客户订单与消息验收

- 新客户首次登录必须填写姓名、店名并保存至少一个地址，资料未完成时禁止下单。
- 客户可维护多个地址、设置默认地址，下单后继续保留收货地址快照。
- 商户逐商品修改成交单价、折扣、减免或运费后，客户必须确认最新报价才能进入待付款。
- 下单、改价、报价确认和状态变化会自动进入对应客户聊天，双方文字消息与未读数应正常更新。
- 客户订单状态只显示中文，且任何客户都不能读取其他客户的订单、报价或聊天。

## 语音消息与容量

- 客户与商户均可录制、试听、发送和播放最长 60 秒的语音；不支持录音的浏览器仍可正常发送文字。
- 语音文件保存到 `UPLOAD_DIR/voice`，生产环境默认位于持久化数据卷 `/data/uploads/voice`，不得改成公开静态目录。
- 语音播放接口会核验当前用户是否为会话双方之一，不能把数据卷文件地址直接提供给外部访问。
- 消息页面每 30 秒使用游标只读取新增消息，页面隐藏时暂停轮询，长聊天不会重复传输完整历史。
- 消息表首次升级到语音类型前会在数据库同目录的 `backups/` 生成一致性备份；发布前仍应额外保留整卷快照和上一版镜像。
- 本地候选环境已验证 100 位注册客户、20 位持续在线和 100 位短时峰值均无 5xx 或数据库锁错误；正式环境上线后需按实际服务器配置复跑 `pnpm run test:load`。
